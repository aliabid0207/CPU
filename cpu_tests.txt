========================================================================================================================
CPU v3 TESTS - self-checking programs
========================================================================================================================
How these work
  Each program checks its own results with CMP + branch. On success it reaches the "pass" HLT; on any failure it
  jumps to its own numbered HLT (f1, f2, ...). The CPU stops on HLT with PC = (address of that HLT) + 8, so
  DBG_PC tells you exactly which check failed. No register debug pins needed.

Test board
  CPU + ROM (64-bit data, address = MADDR[15:3]) feeding MIN.
  TEST 2 also needs RAM at 0x00100000 (the 8 byte lanes) - run TEST 1 first with ROM only.
  CLK and RESET must be ordinary Input pins (a test can't drive a Clock component).

Running
  1. Assemble the source with your assembler (or paste the hex) into the ROM.
  2. Put the matching test table on the test board and run it.
