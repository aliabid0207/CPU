========================================================================================================================================================
CPU v3 - 16 REGISTERS, BYTE ADDRESSED, LOAD/STORE, 64-BIT (compiler-ready)
========================================================================================================================================================
Data width          64 bits (registers, ALU, memory words)
Instruction width   64 bits (one memory word = 8 bytes, PC += 8)
Addressing          BYTE addressed, 32-bit address (MADDR = low 32 bits of the ALU result)
Registers           16 x 64 bits (Register File), R0 always reads 0
Memory              8 byte lanes of 8 bits each, word access must be aligned
Microcode ROM       12 address bits (8 opcode + 4 step), 32 data bits
Datapath            muxes only (no tri-state bus) -> exports to Verilog / FPGA



========================================================================================================================================================
INSTRUCTION FORMAT (64 bits)
========================================================================================================================================================
Bits        Field       Hex digits      Used for
63-56       OPCODE      1st-2nd         what to do
55-52       RD          3rd             destination register
51-48       RS1         4th             first source register (also the base for loads/stores)
47-44       RS2         5th             second source register (also the value to store)
43-32       SPARE       6th-8th         0 for now
31-0        IMM         9th-16th        constant, memory offset, or jump target

Example     0x 10 3 1 2 000 00000000  =  ADD  R3, R1, R2
            0x 18 3 0 0 000 00000005  =  ADDI R3, R0, 5      (LI R3, 5)
            0x 36 3 1 0 000 00000010  =  LD   R3, [R1+16]
            0x 3B 0 1 2 000 00000010  =  SD   R2, [R1+16]
            0x 41 0 0 0 000 00100058  =  BEQ  0x00100058

IMM is sign-extended for ADDI, CMPI, loads and stores (so -8 works), zero-extended for ANDI/ORI/XORI and shifts.



========================================================================================================================================================
REGISTERS AND CONVENTIONS
========================================================================================================================================================
Register    Name    Role
R0          ZERO    always reads 0, writes are ignored
R1-R13              general purpose
R14         LR      link register: CALL saves the return address here
R15         SP      stack pointer: grows downward, points at the last item pushed

Stack is just memory + a convention, no special hardware:
  push Rx:  ADDI SP, SP, -8   then  SD Rx, [SP+0]
  pop  Rx:  LD Rx, [SP+0]     then  ADDI SP, SP, 8
A function that calls other functions must push LR first and pop it before RET.

INSTRUCTION SET
========================================================================================================================================================
Opcode  Name   Assembly               Operation                            Template

-- control
0x00    NOP    NOP                    nothing                              0x0000000000000000
0x01    HLT    HLT                    stop the clock                       0x0100000000000000

-- ALU, register-register
0x10    ADD    ADD rd, rs1, rs2       rd <- rs1 + rs2                      0x10D1200000000000
0x11    SUB    SUB rd, rs1, rs2       rd <- rs1 - rs2                      0x11D1200000000000
0x12    AND    AND rd, rs1, rs2       rd <- rs1 AND rs2                    0x12D1200000000000
0x13    OR     OR rd, rs1, rs2        rd <- rs1 OR rs2                     0x13D1200000000000
0x14    XOR    XOR rd, rs1, rs2       rd <- rs1 XOR rs2                    0x14D1200000000000
0x15    SHL    SHL rd, rs1, rs2       rd <- rs1 << rs2                     0x15D1200000000000
0x16    SHR    SHR rd, rs1, rs2       rd <- rs1 >> rs2 (fill 0)            0x16D1200000000000
0x17    SAR    SAR rd, rs1, rs2       rd <- rs1 >> rs2 (fill sign)         0x17D1200000000000

-- ALU, register-immediate
0x18    ADDI   ADDI rd, rs1, imm      rd <- rs1 + imm (sext)               0x18D10000IIIIIIII
0x19    ANDI   ANDI rd, rs1, imm      rd <- rs1 AND imm (zext)             0x19D10000IIIIIIII
0x1A    ORI    ORI rd, rs1, imm       rd <- rs1 OR imm (zext)              0x1AD10000IIIIIIII
0x1B    XORI   XORI rd, rs1, imm      rd <- rs1 XOR imm (zext)             0x1BD10000IIIIIIII
0x1C    SHLI   SHLI rd, rs1, imm      rd <- rs1 << imm                     0x1CD10000IIIIIIII
0x1D    SHRI   SHRI rd, rs1, imm      rd <- rs1 >> imm (fill 0)            0x1DD10000IIIIIIII
0x1E    SARI   SARI rd, rs1, imm      rd <- rs1 >> imm (fill sign)         0x1ED10000IIIIIIII
0x1F    LUI    LUI rd, imm            rd <- imm << 32                      0x1FD00000IIIIIIII

-- compare (sets flags, writes nothing)
0x20    CMP    CMP rs1, rs2           flags <- rs1 - rs2                   0x2001200000000000
0x21    CMPI   CMPI rs1, imm          flags <- rs1 - imm                   0x21010000IIIIIIII

-- loads (address = rs1 + imm)
0x30    LB     LB rd, [rs1+imm]       rd <- byte, sign-extended            0x30D10000IIIIIIII
0x31    LBU    LBU rd, [rs1+imm]      rd <- byte, zero-extended            0x31D10000IIIIIIII
0x32    LH     LH rd, [rs1+imm]       rd <- 16 bits, sign-extended         0x32D10000IIIIIIII
0x33    LHU    LHU rd, [rs1+imm]      rd <- 16 bits, zero-extended         0x33D10000IIIIIIII
0x34    LW     LW rd, [rs1+imm]       rd <- 32 bits, sign-extended         0x34D10000IIIIIIII
0x35    LWU    LWU rd, [rs1+imm]      rd <- 32 bits, zero-extended         0x35D10000IIIIIIII
0x36    LD     LD rd, [rs1+imm]       rd <- 64 bits                        0x36D10000IIIIIIII

-- stores (address = rs1 + imm)
0x38    SB     SB rs2, [rs1+imm]      byte <- low 8 bits of rs2            0x38012000IIIIIIII
0x39    SH     SH rs2, [rs1+imm]      16 bits <- rs2                       0x39012000IIIIIIII
0x3A    SW     SW rs2, [rs1+imm]      32 bits <- rs2                       0x3A012000IIIIIIII
0x3B    SD     SD rs2, [rs1+imm]      64 bits <- rs2                       0x3B012000IIIIIIII

-- jumps and branches (branches use the flags from the last CMP/CMPI)
0x40    JMP    JMP target             PC <- imm                            0x40000000IIIIIIII
0x41    BEQ    BEQ target             jump if equal                        0x41000000IIIIIIII
0x42    BNE    BNE target             jump if not equal                    0x42000000IIIIIIII
0x43    BLT    BLT target             jump if less (signed)                0x43000000IIIIIIII
0x44    BGE    BGE target             jump if greater/equal (signed)       0x44000000IIIIIIII
0x45    BLTU   BLTU target            jump if less (unsigned)              0x45000000IIIIIIII
0x46    BGEU   BGEU target            jump if greater/equal (unsigned)     0x46000000IIIIIIII
0x48    CALL   CALL target            LR <- PC, PC <- imm                  0x48000000IIIIIIII
0x49    JR     JR rs1                 PC <- rs1                            0x4901000000000000
0x4A    CALLR  CALLR rs1              LR <- PC, PC <- rs1                  0x4A01000000000000

Template key: D = rd, 1 = rs1, 2 = rs2, IIIIIIII = imm.
Alignment: LH/SH need an even address, LW/SW a multiple of 4, LD/SD a multiple of 8.

Pseudo-instructions (the assembler turns these into real ones)
LI   rd, imm        = ADDI rd, R0, imm          (imm is sign-extended: fine for any address, since MADDR
                                                 only uses the low 32 bits; for numbers >= 0x80000000 use LUI + ORI)
MOV  rd, rs         = ADD  rd, rs, R0
RET                 = JR   LR
NEG  rd, rs         = SUB  rd, R0, rs
NOT  rd, rs         = ADDI R13, R0, -1  then  XOR rd, rs, R13     (uses R13 as scratch)
64-bit constant     = LUI rd, high32  then  ORI rd, rd, low32

MICROCODE
========================================================================================================================================================
Microcode address = [ opcode AND (step != 0) ] x 16 + step     (same trick as v2: FETCH lives once at 0x000)
Every instruction is FETCH (step 0) + ONE execute step (step 1), which always ends with STEP_RESET.

========================================================================================================================================================
CONTROL SIGNALS
========================================================================================================================================================
Bit     Signal          Hex value       Wire goes to
0       IR_LOAD         0x00000001      IR register en
1       PC_INC          0x00000002      PC: next = PC + 8
2       ADDR_ALU        0x00000004      MADDR mux: 0 = PC, 1 = ALU result (low 32 bits)
3       MEM_WRITE       0x00000008      MWR output pin
4       REG_WRITE       0x00000010      Register File we
5-6     WB_SEL          0x00000020 x n  write-back mux: 0 = ALU result, 1 = load result, 2 = PC (return address)
7       RD_LINK         0x00000080      Register File Rw = 14 (LR) instead of rd
8       ALU_SRC_IMM     0x00000100      ALU input B mux: 0 = rs2 value, 1 = immediate
9-10    IMM_SEL         0x00000200 x n  immediate: 0 = sign-extend, 1 = zero-extend, 2 = imm << 32
11-14   ALU_OP          0x00000800 x n  ALU operation (table below)
15      FLAGS_LOAD      0x00008000      Z, N, C, V registers en
16      BRANCH          0x00010000      jump logic
17-19   COND            0x00020000 x n  branch condition (table below)
20      PC_SRC_REG      0x00100000      jump target mux: 0 = imm, 1 = rs1 value
21-22   MSIZE           0x00200000 x n  memory size: 0 = byte, 1 = 16 bits, 2 = 32 bits, 3 = 64 bits
23      MSIGNED         0x00800000      load formatter: sign-extend instead of zero-extend
24      STEP_RESET      0x01000000      step counter clear
25      HALT            0x02000000      clock gate
26-31   (spare)

ALU_OP  Operation                       COND    Taken when          Meaning
0       ADD     A + B                   0       always              JMP, CALL, JR
1       SUB     A - B                   1       Z                   equal
2       AND     A AND B                 2       NOT Z               not equal
3       OR      A OR B                  3       N XOR V             less than (signed)
4       XOR     A XOR B                 4       NOT (N XOR V)       greater or equal (signed)
5       SHL     A << B[5:0]             5       NOT C               less than (unsigned)
6       SHR     A >> B[5:0], fill 0     6       C                   greater or equal (unsigned)
7       SAR     A >> B[5:0], fill sign  7       never
8       PASS_B  B



========================================================================================================================================================
FLAGS (set only by CMP / CMPI, i.e. ALU = SUB with FLAGS_LOAD)
========================================================================================================================================================
Z - Zero      result == 0
N - Negative  result bit 63
C - Carry     ALU carry out (1 = NO borrow, i.e. rs1 >= B unsigned)
V - Overflow  (A63 != B63) AND (R63 != A63)       signed overflow of A - B
Each is a 1-bit register, D <- ALU, en = FLAGS_LOAD, rising edge.



========================================================================================================================================================
DATAPATH (no bus: every value goes through a mux)
========================================================================================================================================================
Part            Inputs                                                      Output to
IR              D <- MIN, en = IR_LOAD                                       field splitter (op, rd, rs1, rs2, imm)
REG FILE        Ra = rs1, Rb = rs2, Rw = RD_LINK ? 14 : rd,                  Da, Db
                Din = write-back mux, we = REG_WRITE
R0 FIX          Da' = (rs1 == 0) ? 0 : Da,   Db' = (rs2 == 0) ? 0 : Db        ALU A, ALU B mux, store formatter, jump target mux
IMM GEN         imm (32) -> SEXT / ZEXT / HI by IMM_SEL                      ALU B mux
ALU B MUX       Db' or IMM64, select ALU_SRC_IMM                             ALU B
ALU             A = Da', B = mux, op = ALU_OP                                write-back mux, MADDR mux, flags
MADDR MUX       PC or ALU result low 32 bits, select ADDR_ALU                MADDR pin, lane bits 2-0
LOAD FORMATTER  MIN, lane, MSIZE, MSIGNED                                     write-back mux
STORE FORMATTER Db', lane, MSIZE                                              MOUT pin, MBE pin
WRITE-BACK MUX  ALU result / load result / PC, select WB_SEL                 Register File Din
JUMP TARGET MUX imm or Da' low 32 bits, select PC_SRC_REG                    PC next-value mux
PC              Register, 32 bits, clock = NOT CPU clock (falling)           MADDR mux, write-back mux (link)

Load formatter:  shifted = MIN >> (lane x 8)   (Barrel shifter, shift = lane bits << 3)
                 byte: low 8 bits, half: low 16, word: low 32, dword: all 64
                 then sign- or zero-extend to 64 (Bit Extenders + a 4-input mux on MSIZE, MSIGNED picks sext/zext)
Store formatter: MOUT = Db' << (lane x 8)
                 MBE  = size mask << lane      size mask: byte 0x01, half 0x03, word 0x0F, dword 0xFF



========================================================================================================================================================
REGISTERS (clocked parts)
========================================================================================================================================================
Name        Width   Built from          Clock           Load / control
REG FILE    16x64   Register File       rising          we = REG_WRITE
IR          64      Register            rising          en = IR_LOAD
Z, N, C, V  1 each  Register            rising          en = FLAGS_LOAD
PC          32      Register            falling (NOT)   en = PC_INC OR JUMP OR RESET
STEP        4       Counter             falling (NOT)   en = 1, clr = STEP_RESET OR RESET



========================================================================================================================================================
EXTRA LOGIC
========================================================================================================================================================
Microcode addr = [ opcode AND (OR of step bits) ] , [ step ]       (opcode bits 11-4, step bits 3-0)
COND_TRUE      = 8-input mux on COND: 1, Z, NOT Z, N XOR V, NOT(N XOR V), NOT C, C, 0
JUMP           = BRANCH AND COND_TRUE
PC next        = RESET ? 0 : JUMP ? jump target : PC + 8
CPU clock      = CLK AND (NOT HALT OR RESET)
CLK_OUT        = CPU clock

========================================================================================================================================================
MEMORY MAP (MOTHERBOARD, byte addresses)
========================================================================================================================================================
Address                     Device      Access      Notes
0x00000000 - 0x0000FFFF     BOOT ROM    read        64-bit ROM, address = MADDR[15:3] (13 bits, 8192 words), PC starts here
0x00100000 - 0x001FFFFF     RAM         read/write  1 MB = 8 lanes x 131072 bytes, lane address = MADDR[19:3] (17 bits)
0xE0000000 - 0xE000FFFF     CARTRIDGE   read        64-bit ROM, address = MADDR[15:3]
0xF0000000                  X0          read        input 0 (first number)
0xF0000008                  X1          read        input 1 (second number)
0xF0000010                  X2          read        input 2 (operator)
0xF0000018                  X3          read        input 3 (equals button)
0xF0000100                  DISPLAY     write (SD)  64-bit register driving the display

Board wiring
Region          = MADDR[31:20]: 0x000 BOOT, 0x001 RAM, 0xE00 CART, 0xF00 I/O   (comparators, or decode bits 31-28 + bit 20)
MIN             = 4-input mux on region (BOOT, RAM, CART, I/O)
RAM lane i      = 8-bit RAM: A = MADDR[19:3], Din = MOUT[8i+7 : 8i], str = MWR AND RAM region AND MBE[i], C = CLK_OUT, ld = 1
                  the 8 lane outputs merge (lane 0 = bits 0-7 ... lane 7 = bits 56-63) into MIN's RAM input
Input ports     = 4-input mux on MADDR[4:3] -> MIN's I/O input
DISPLAY         = Register, D = MOUT, en = MWR AND (MADDR == 0xF0000100), C = CLK_OUT

========================================================================================================================================================
BOOTLOADER (BOOT ROM, 0x00000000)
========================================================================================================================================================
Cartridge format: word 0 = N (number of program words), words 1..N = the program.
Copies the N program words to RAM 0x00100000, sets SP, then jumps there.

Address      Hex                  Label    Instruction                  Meaning
0x00000000   0x18100000E0000000            LI R1, 0xE0000000            R1 = cartridge pointer
0x00000008   0x3621000000000000            LD R2, [R1+0]                R2 = N (program length in words)
0x00000010   0x1811000000000008            ADDI R1, R1, 8               skip the header word
0x00000018   0x1830000000100000            LI R3, 0x00100000            R3 = RAM pointer
0x00000020   0x2102000000000000   loop     CMPI R2, 0                   words left?
0x00000028   0x4100000000000060            BEQ done                     
0x00000030   0x3651000000000000            LD R5, [R1+0]                copy one word
0x00000038   0x3B03500000000000            SD R5, [R3+0]                
0x00000040   0x1811000000000008            ADDI R1, R1, 8               advance both pointers
0x00000048   0x1833000000000008            ADDI R3, R3, 8               
0x00000050   0x18220000FFFFFFFF            ADDI R2, R2, -1              one fewer left
0x00000058   0x4000000000000020            JMP loop                     
0x00000060   0x18F0000000200000   done     LI SP, 0x00200000            stack pointer = top of RAM
0x00000068   0x4000000000100000            JMP 0x00100000               run the program
